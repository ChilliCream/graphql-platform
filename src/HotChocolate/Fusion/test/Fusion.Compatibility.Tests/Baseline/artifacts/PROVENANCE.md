## Regenerating

Run `../build-baseline.sh` from this directory's parent (`Baseline/`). It rebuilds
`BaselineConsumer.csproj` in isolation (its own `Directory.Build.props` /
`Directory.Packages.props` stop MSBuild's property walk-up, so only the pinned NuGet packages
above are restored, never local project output), copies the resulting DLL here, and regenerates
the `.sha256` file. Update the tables above by hand afterwards.
